- 방식: serve-sim의 실제 시뮬레이터 화면을 Codex 브라우저에 미러링하고 클릭·길게 누르기로 조작
- 상태: 기존 위젯의 중간·큰 크기 배치, 라이트·다크, 실제 행/배경 탭 및 관심 변경 반영 확인. 갤러리 신규 추가와 일부 데이터 조합은 미완료.
- 제품 코드는 변경하지 않았다. 이 브랜치는 검증 기록과 캡처만 추가한다.

## 실제 관찰 결과

실제 홈 화면에 이미 배치돼 있던 관심 법안 위젯을 사용했다. 갤러리에서 새로 추가한 것으로 기록하지 않는다. 초기 위젯에는 테스트용 `법안 A`가 남아 있었고, 해당 행을 누르면 상세 화면이 열렸지만 데이터 조회는 실패했다. 이후 앱 관심 목록의 실제 법안을 열고 읽음 처리해 스냅샷을 갱신한 뒤 아래 검증을 진행했다. 테스트용 표시를 실제 법안의 정상 조회로 오인하지 않았다.

검증 법안: 부동산개발업의 관리 및 육성에 관한 법률 일부개정법률안 (의안번호 2222308, 제22대, 위원회 단계).

| 항목 | 실제 관찰 | 판정 |
| --- | --- | --- |
| 중간 배치 | 실제 법안 1행의 긴 제목은 말줄임 처리되고 단계·변동 없음·발의 건수 미확인·관심 조회 시각 미확인이 겹치지 않음 | 확인 |
| 큰 배치 | 기존 위젯 길게 누르기 → 큰 크기 선택. 1행과 하단 안내가 정상 배치됨 | 확인 |
| 라이트·다크 | 중간·큰 크기 모두 실제 홈 호스팅에서 텍스트와 단계·배경 표시 확인 | 확인 |
| 중간 행 탭 | 앱이 실행돼 있는 상태에서 해당 법안 상세로 이동 | 확인 |
| 큰 행 탭 / 앱 종료 후 | 앱을 종료한 뒤 실제 홈 위젯 행을 눌러 같은 법안 상세가 로드됨 | 확인 |
| 배경 탭 / 변동 없음 | 상세 화면이 남아 있던 상태에서 위젯 빈 영역을 누르면 홈 루트로 이동하고 홈 탭이 선택됨 | 확인 |
| 읽음 처리 | 앱 상세 진입 후 테스트용 법안 대신 실제 관심 법안과 변동 없음으로 홈 위젯 갱신 | 확인 |
| 관심 해제 | 별 버튼으로 해제한 뒤 큰 위젯이 '담아둔 법안이 없습니다'로 갱신 | 확인 |
| 관심 복원 | 같은 법안을 다시 관심에 추가하면 큰 위젯에 해당 행 복원 | 확인 |
| 환경 복원 | 관심 법안 1건 복원, 위젯 중간 크기·라이트 모드로 복원 | 확인 |
| 시스템 갤러리 | 위젯 검색창만 보이며 애플 기본 위젯을 포함해 목록이 비어 있음 | 환경 문제 재현, 신규 추가 미검증 |

이 결과는 실제 WidgetKit 홈 화면의 관찰이다. 최대 2/5행 배치, 모든 데이터 상태, 실기기 동작까지 검증한 것은 아니다.

## 환경 복구 과정

처음 XcodeBuildMCP의 홈 버튼은 성공 응답을 반환했지만 화면 전환이 확인되지 않았다. Device Hub 직접 제어는 컴퓨터 제어 권한 부족으로 거부됐다. 따라서 이 응답을 홈 화면 검증으로 인정하지 않았다.

serve-sim 브라우저 미러링은 실시간 프레임을 표시했지만 초기 입력이 전달되지 않았다. 도구의 공식 안내대로 대상 시뮬레이터의 `repair-input`을 실행하고 해당 미러링 서버를 재시작하자 실제 탭·길게 누르기가 동작했다. [serve-sim 공식 안내](https://github.com/EvanBacon/serve-sim)

갤러리 진입 후에는 시스템 UI가 비어 있고 홈 복귀도 되지 않아 SpringBoard와 미러링 서버를 재시작했다. 앱 데이터나 시뮬레이터를 초기화하지 않았다. 기존 위젯의 크기 선택 메뉴로 큰 크기를 검증했다. 위젯 갤러리 문제가 앱 코드 때문이라고 단정하지 않는다.

외관 변경 중 애플 지도의 위치 권한 팝업이 나타났고 위치 접근은 허용하지 않았다. TodayBill의 위치 권한이나 제품 설정은 변경하지 않았다.

## 남은 검증

- 정상 작동하는 시스템 갤러리에서 TodayBill 검색 및 중간·큰 위젯 신규 추가.
- 중간 최대 2행, 큰 최대 5행 및 '외 N건 변동'의 최대 콘텐츠 조합.
- 스냅샷 없음, 관심 목록 미확인, 실제 변동 있음/부분 실패, 오래된 관심·발의 정보가 겹치는 조합.
- 변동 있음 배경 탭의 관심 루트 이동과 잘못된 age 행의 대체 이동 실물 확인.
- 앱 종료 상태의 배경 탭 홈 이동 및 다양한 기존 navigation stack 조합.
- 실제 시간 경과에 따른 자정·6시간 전환과 백그라운드 갱신, iOS 16.4 및 실기기.

날짜·경합·라우팅·부분 실패의 모델/통합 테스트 통과는 기존 기록대로 유효하지만 위 항목의 실물 검증을 대신하지 않는다. 현재까지 관찰한 범위에서 제품 수정이 필요한 결함은 재현되지 않았다. 검색 필터 구현은 별도 브랜치 범위로 유지한다.
