아래 항목은 아직 통과로 판단하지 않는다. 앱 내 렌더링, URL 직접 실행, 자동 테스트로 실제 WidgetKit 호스팅과 터치를 대신하지 않는다.

## 현재 환경 제약

XcodeBuildMCP의 home 버튼은 성공 응답을 반환했지만, 후속 스크린샷은 여전히 앱 화면이었다. 따라서 실제 홈 이동이 됐다고 판단하지 않았다. Simulator를 열고 재시도해도 같은 상태였다.

Device Hub에 대한 직접 컴퓨터 제어는 `Computer Use permissions are not granted`로 거부됐다. 권한을 허용하거나 사용자가 직접 홈 화면에서 위젯을 배치해야 실제 사용 경로의 검증을 이어갈 수 있다. 이번 시도에서 위젯 갤러리 화면에는 도달하지 못했으므로, 과거의 빈 갤러리 문제가 현재도 재현된다고 단정하지 않는다.
